# Requirements — IT Support Chatbot

## FR-01: Registro de Ticket
- El usuario ingresa descripción del problema
- El sistema genera ID único (formato: TKT-YYYYMMDD-XXX)
- Se registra fecha, hora, descripción y usuario

## FR-02: Clasificación Automática
- Categorías: Hardware, Software, Red, Acceso
- Clasificación por palabras clave
- Prioridad: Alta, Media, Baja

## FR-03: Consulta de Ticket
- Búsqueda por ID de ticket
- Respuesta con estado, categoría y prioridad
