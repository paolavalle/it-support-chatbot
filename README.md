# 🤖 IT Support Chatbot

Sistema de chatbot para soporte técnico IT desarrollado en Python.
Permite registrar, clasificar y consultar tickets de soporte.

## 📋 Descripción
Este proyecto resuelve la necesidad de automatizar la recepción
y clasificación de solicitudes de soporte IT, reduciendo tiempos
de atención y mejorando la organización de incidencias.

## 🚀 Tecnologías
- Python 3.10+
- JSON (almacenamiento local)
- unittest (pruebas)

## ⚙️ Instalación
git clone https://github.com/paolavalle/it-support-chatbot.git
cd it-support-chatbot
python src/chatbot.py

## ✅ Funcionalidades
- Registro de tickets con ID único
- Clasificación automática por categoría
- Consulta de estado por ID
